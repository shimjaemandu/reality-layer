# Reality Layer v1.3 — Orchestrator

Project 001의 v1.3은 **한 문장의 상위 의도를 여러 현실 행동으로 안전하게 분해하고 실행하는 Orchestrator**를 추가한다.

## 핵심 구조

```text
High-level intent
  ↓
Reality Orchestrator
  ↓  plan / ordering / skip / stop
Identity + Context Graph + Device Graph
  ↓
Permission + Safety Policy
  ↓
AUTO / CONFIRM / BLOCKED
  ↓
UAG/0.1
  ↓
Device Adapter
  ↓
PC / Light / Display / Door
```

Orchestrator 자체가 권한을 부여하지 않는다. **각 Step은 기존 Reality Policy를 독립적으로 통과해야 한다.**

## v1.3에서 추가된 것

- `reality-orchestrator/1.3`
- 상위 의도 → ordered multi-step plan
- 각 Step별 Device Graph / Context Graph / Permission / Safety 평가
- 각 Step별 UAG 공통 명령 생성
- `AUTO / CONFIRM / BLOCKED`를 계획 수준으로 합성
- 다른 재실자가 있는 공간의 환경 변경 자동 생략
- 선택 단계 실패 시 계속 진행
- 필수 단계 실패 시 계획 중단
- 계획 생성 뒤 Identity / Device Graph / Context Graph가 바뀌면 stale plan 폐기
- 실행 결과를 Action Log에 plan/step 메타데이터와 함께 기록
- UI에서 계획 생성 → Step 검토 → 확인 → 실행 가능

## 현재 지원하는 상위 의도

### 1. `나 이제 나갈게` — 외출 준비

1. 거실 조명 OFF — 다른 재실자가 있으면 생략
2. 침실 조명 OFF — 다른 재실자가 있으면 생략
3. 안내 디스플레이 OFF — 다른 재실자가 있으면 생략
4. 개인 노트북 잠금 — Permission에 따라 확인 필요
5. 현관문 잠금 — 필수 단계, 확인 필요

예: Family가 거실에 있으면 거실 조명 OFF는 계획에서 `SKIPPED`가 된다.

### 2. `나 잘게` — 취침 준비

- 거실 조명 OFF
- 안내 디스플레이 OFF
- 침실 밝기 20%
- 개인 노트북 잠금

다른 사람이 영향을 받는 Step은 Context Graph를 보고 생략하거나 Policy 확인을 요구한다.

### 3. `공부 시작할게` — 공부 준비

- 침실 조명 ON
- 침실 밝기 80%
- 노트북 공부 Workflow 실행

## 계획 안전성

계획 생성 시 각 실행 Step에 다음 snapshot을 저장한다.

- Identity
- Device Graph
- Context Graph

실행 직전에 snapshot이 현재 현실 상태와 다르면 **전체 계획을 실행하지 않고 다시 계획하도록 요구한다.**

예:

```text
Plan 생성: Family = 침실
↓
Family가 거실로 이동
↓
Plan 실행 요청
↓
Context Graph fingerprint 불일치
↓
STALE PLAN → 실행 차단 → 다시 계획
```

## 실행

Node.js 18 이상 필요.

```bash
npm start
```

브라우저:

```text
http://127.0.0.1:3000
```

테스트:

```bash
npm test
```

Windows가 아닌 환경에서는 테스트가 실제 PC 행동을 실행하지 않도록 `PC_ADAPTER_DRY_RUN=1`을 사용한다.

## 주요 API

- `GET /api/orchestrator` — Orchestrator 스펙
- `POST /api/orchestrate-plan` — 상위 의도에서 계획 생성
- `POST /api/orchestrate-execute` — 생성된 계획 실행
- 기존 `/api/interpret`, `/api/execute` 단일 행동 API도 그대로 유지

계획 생성 예:

```json
{
  "text": "나 이제 나갈게"
}
```

계획 실행 예:

```json
{
  "plan_id": "...",
  "confirmed": true
}
```

## 아직 하지 않는 것

- 임의 LLM이 무제한으로 새 행동을 생성하는 것
- 임의 PowerShell / cmd 실행
- 임의 파일 삭제
- 실제 도어락 연결
- 제조사 API 무제한 호출
- 긴 시간 동안 자율적으로 행동하는 Agent loop

v1.3의 목적은 **자율성 확대가 아니라, 여러 현실 행동을 안전하게 조율하는 구조를 검증하는 것**이다.
