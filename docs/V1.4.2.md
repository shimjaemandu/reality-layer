# v1.4.2 실사용 안정화

- 웹 URL/사이트/검색은 Microsoft Edge를 우선 직접 실행하고 Edge를 찾지 못할 때만 Windows 기본 연결로 폴백합니다.
- VS Code 탐색 경로를 LocalAppData, Program Files, Program Files (x86), Scoop, WindowsApps, Chocolatey, PATH로 확대했습니다.
- 연결 탭에서 안전하게 Windows `.exe` 전체 경로를 `apps.local.json`에 등록할 수 있습니다. 등록 파일은 Git에서 제외됩니다.
- 애매한 단일 명령은 임의 실행하지 않고 clarification 응답과 선택지를 제공합니다.
- 기존 Permission / Safety / Context / Device Graph 검증은 그대로 유지합니다.
