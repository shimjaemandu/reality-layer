# v1.5 Capability Runtime

## 목표

Reality Layer의 내부 실행 언어를 고정 명령 중심에서 **Capability Model + Typed Action IR** 중심으로 전환합니다.

## 새 Core

- `src/capability-model.js` — 기기 타입별 capability, 입력 스키마, risk, reversible/idempotent metadata
- `src/action-ir.js` — `reality-action/1.0` typed action envelope
- `src/executor.js` — Action IR 검증 후 기존 Adapter로 호환 변환

## 예시

기존 조명 명령:

```json
{ "action": "set_brightness", "brightness": 80 }
```

v1.5 내부 표현:

```json
{
  "schema": "reality-action/1.0",
  "target": { "device_id": "bedroom_light", "device_type": "light" },
  "capability": { "id": "brightness", "kind": "property" },
  "operation": "write",
  "input": { "value": 80 },
  "semantics": { "risk": "low", "reversible": true, "idempotent": true }
}
```

## 호환 전략

기존 Windows/Home Assistant/가상 Adapter는 이번 버전에서 다시 작성하지 않습니다. Executor가 Action IR을 검증한 뒤 마지막 단계에서만 legacy command로 변환합니다. 이 bridge는 이후 Protocol Connector 구조가 들어올 때 제거/축소할 수 있습니다.

## API

- `GET /api/capability-model`
- `GET /api/action-ir`
- `GET /api/device-registry` 응답에 capability model과 Action IR spec 포함
- `/api/interpret`, Orchestrator step, audit log에 `action_ir` 포함
