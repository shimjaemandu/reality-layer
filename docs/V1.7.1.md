# Reality Layer v1.7.1

v1.7.1 is a compatibility patch for v1.7. It keeps the 2026-07-28 modern MCP path and adds the 2025-era `initialize` + `Mcp-Session-Id` lifecycle used by clients such as Gemini CLI v0.60.0 / MCP SDK 1.x.

## What changed

- Existing 2026-07-28 `server/discover` flow remains supported.
- Adds legacy MCP `initialize`, `notifications/initialized`, `ping`, `tools/list`, and `tools/call`.
- Adds per-client legacy sessions using `Mcp-Session-Id`.
- Captures `clientInfo` from `initialize` for audit metadata.
- Adds authenticated `DELETE /mcp` session cleanup.
- Keeps Reality Layer Identity/Permission/Safety authoritative. MCP client identity remains audit metadata only.

This patch changes protocol compatibility, not the Reality Layer policy model.
