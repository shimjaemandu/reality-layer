# v1.4.3 Windows 앱 자동 탐색 안정화

실제 노트북 테스트에서 VS Code가 표준 설치 경로에 없을 때 수동 `.exe` 등록도 실패하는 문제를 개선했습니다.

## 변경점

- 앱 탐색 순서: 등록/표준 경로 → `where.exe`/PATH → Windows 시작 메뉴 `Get-StartApps`.
- 시작 메뉴 AppID만 발견되는 앱도 `shell:AppsFolder`로 실행 가능.
- 연결 화면에 **VS Code 자동 찾기** 버튼 추가.
- 수동 경로 입력에서 따옴표, 환경변수, 뒤쪽 인자를 정리.
- 수동 경로가 틀려도 동일 앱을 자동 탐색할 수 있으면 자동 발견 결과를 사용.
- 웹 검색 Edge 우선, clarification, Reality Layer Core 정책은 유지.

## 보안 경계

PowerShell은 AI가 자유롭게 명령을 실행하는 기능으로 노출하지 않습니다. v1.4.3에서 사용하는 PowerShell 호출은 Windows 시작 메뉴 앱 목록을 읽기 위한 고정된 내부 탐색 명령뿐입니다. 임의 PowerShell/cmd 실행은 계속 지원하지 않습니다.
