# v1.4.1 hardening

- Runtime privacy: `data/*.json` and temporary state are Git-ignored; clean distributions start without personal state.
- Application boundary: Everyday implementation moved under `src/apps/everyday/`; compatibility wrappers keep previous imports working.
- Identity semantics: Owner/Family/Guest are explicitly demo policy identities, not real authentication.
- Future physical-access guard: non-virtual security-perimeter devices are blocked until a `real_world_verified` identity exists.
- OpenAI default: `gpt-5.6-luna` for cost-sensitive structured intent parsing; API-key-free local fallback is unchanged.
