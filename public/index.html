ONE LAYER, MANY DEVICES

기기가 연결되면, 일상이 움직여요.

기기마다 다른 제어 방식을 공통 명령으로 연결해요.

Windows 앱 경로 등록

자동으로 못 찾는 앱은 실행 파일(.exe) 경로를 한 번 등록하면 돼요. VS Code 예: C:\Users\내이름\AppData\Local\Programs\Microsoft VS Code\Code.exe

앱 상태를 불러오는 중…

실제 기기 연결

  1. 먼저 이 화면에서 체험하기

    추가 기기나 API 키 없이 기본 일상 명령을 실행해 보세요.

  2. Windows 노트북 연결

    현재 실행 창을 닫고 START-WINDOWS.cmd를 실행하면 메모장 등 등록한 앱을 실제로 열 수 있어요.

  3. Home Assistant 조명 연결

    config.example.json을 config.local.json으로 복사하고 내 Home Assistant 주소·토큰·조명 ID를 입력해요. 토큰은 화면에 표시하지 않아요. 실제 연결 모드로 다시 시작해 주세요.

Home Assistant에 미리 연결된 조명이 필요해요. 실제 하드웨어와 마이크는 이 개발 환경에서 검증하지 못했어요.

AI 자연어 해석 사용하기

config.local.json에 OpenAI API 키를 넣으면 개별 기기 명령의 다양한 표현을 해석해요. 키가 없으면 정해진 일상 표현과 로컬 해석기로 작동해요. 일상 순서는 검증된 규칙으로 구성해요. API 사용료는 별도이며, AI 해석을 쓰면 입력한 명령과 기기·공간 정보가 OpenAI로 전송돼요.

현재 연결 범위

이 노트북 안에서 사용하는 시제품이에요. 계정 로그인, 스마트폰 원격 연결, 자동차·로봇 제어, 자동 위치 감지는 아직 구현 범위에 포함되지 않아요.
