1. ZIP 파일을 완전히 압축 해제하세요.
2. Node.js 22 이상이 설치된 노트북에서 START-DEMO.cmd를 더블클릭하세요.

실제 PC 제어는 Demo를 종료한 뒤 START-WINDOWS.cmd로 시작합니다.
Windows 웹 열기/검색은 Microsoft Edge를 우선 사용합니다.
VS Code는 자동 탐색하며, 필요하면 연결 탭에서 자동 찾기를 실행하세요.

/api/event-store    = 과거 이벤트

v1.8.2 MCP / External action contract:
- Endpoint: http://127.0.0.1:3000/mcp
- Protocol: MCP 2026-07-28 modern stateless
- 외부 Agent용 Bearer token은 실행 터미널에 표시됩니다.
- reality.discover / observe / plan / execute / explain
- reality.action.get / reality.action.reconcile
- reality.execute 결과에 action_id / outcome / provenance / reconciliation 상태가 직접 포함됩니다.
- UNKNOWN은 blind retry하지 말고 외부 evidence로 reconciliation 후 다음 동작을 결정합니다.
- 외부 Agent는 CONFIRM 단계의 사용자 확인을 스스로 승인할 수 없습니다.
